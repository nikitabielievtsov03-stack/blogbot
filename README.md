# BlogBot — Telegram-бот для управления контент-планом @belevtsow

Бот помогает вести Instagram-блог: загружает контент-план, присылает уведомления, отслеживает серию публикаций и сохраняет идеи для постов.

## Возможности

- **Импорт контент-плана** — из Google Sheets или текстом прямо в чат
- **Уведомления:**
  - За день до поста (21:00)
  - В день поста (09:00)
  - За 2 часа до прайм-тайма (18:00 при прайм-тайме 20:00)
- **Статус поста** — напиши «готово» или /done, и пост отмечается опубликованным
- **Серия публикаций (streak)** — считает дни подряд без пропуска
- **Еженедельный дайджест** — план на следующую неделю каждое воскресенье в 10:00
- **Быстрые заметки** — любое сообщение сохраняется как идея
- **Статистика недели** — сколько постов вышло из запланированных

## Команды бота

| Команда   | Описание                                  |
|-----------|-------------------------------------------|
| /start    | Приветствие и список команд               |
| /help     | Справка                                   |
| /plan     | Посты на сегодня и завтра                 |
| /week     | План на текущую неделю                    |
| /done     | Отметить сегодняшний пост опубликованным  |
| /streak   | Текущая серия и рекорд                    |
| /ideas    | Список сохранённых идей                   |
| /stats    | Статистика за неделю                      |
| /sync     | Синхронизировать план из Google Sheets     |
| /import   | Загрузить план текстом                    |

## Установка

### 1. Клонировать репозиторий

```bash
git clone <repo-url>
cd blogbot
```

### 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Настроить переменные окружения

```bash
cp .env.example .env
```

Заполни `.env`:

- `TELEGRAM_BOT_TOKEN` — токен от @BotFather
- `TELEGRAM_USER_ID` — твой Telegram ID (узнать у @userinfobot)
- `GOOGLE_SHEET_ID` — ID Google таблицы (из URL)
- `GOOGLE_CREDENTIALS_PATH` — путь к JSON-файлу сервисного аккаунта Google

### 4. Настроить Google Sheets API (опционально)

1. Создай проект в [Google Cloud Console](https://console.cloud.google.com/)
2. Включи Google Sheets API
3. Создай сервисный аккаунт и скачай JSON-ключ
4. Положи файл в корень проекта как `credentials.json`
5. Дай сервисному аккаунту доступ к Google-таблице (поделись таблицей с email сервисного аккаунта)

### 5. Формат Google-таблицы

| Дата       | День недели | Формат   | Тема                          | Статус     |
|------------|-------------|----------|-------------------------------|------------|
| 07.04.2026 | Пн          | Reels    | История бренда 12STOREEZ      | planned    |
| 08.04.2026 | Вт          | карусель | Воронка продаж в fashion      | planned    |
| 09.04.2026 | Ср          | Reels    | Как запустить бренд с нуля    | planned    |

### 6. Запустить бота

```bash
python main.py
```

## Импорт плана текстом

Отправь боту команду `/import` с планом:

```

08.04.2026 | Вт | карусель | Воронка продаж в fashion
09.04.2026 | Ср | сторис | Backstage съёмки
```
